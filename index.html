Fitur Utama

Dibuat untuk ASN, dioptimalkan untuk integritas

Semua yang dibutuhkan untuk pelaporan kepentingan pribadi: dari pengisian hingga rekap admin, dalam satu aplikasi ringan tanpa XAMPP.

📝

Formulir Digital Lengkap A–F

Identitas, hubungan keluarga, bisnis, pekerjaan lain, rangkap jabatan, afiliasi, hingga rencana pasca pensiun — sesuai format resmi.

✍️

Tanda Tangan Digital Halus

Canvas 2x retina, undo, hapus, auto-save ke browser. Disimpan sebagai PNG base64 dan ikut tercetak rapi A4.

☁️

Simpan Otomatis & Offline-Tolerant

Isian tersimpan di localStorage agar tidak hilang. Tombol “Simpan ke Database” kirim ke Neon (online) atau MySQL (localhost) otomatis.

🔐

Admin Aman dengan JWT

Login admin pakai ENV Vercel, token JWT 8 jam, filter status, detail JSON, update status, dan export CSV dengan BOM UTF-8.

🖨️

Cetak Rapi A4

Layout print-friendly, kop dinas, tabel auto-resize, tanda tangan tetap terbaca. Siap arsip atau PDF.

⚡

Deploy 1-Menit di Vercel

Tanpa server. Cukup set DATABASE_URL, ADMIN_USER, ADMIN_PASS, ADMIN_SECRET lalu deploy. Sudah termasuk CORS & rewrites.

Alur Kerja

3 langkah selesai, data langsung masuk rekap

Dirancang agar pegawai tidak bingung, admin tidak repot.

Buka Formulir

Klik “Isi Formulir” — tidak perlu login. Isi Nama, NIP, pangkat, jabatan, dan bagian A–F.

Tanda Tangan & Periksa

Gambar tanda tangan dengan mouse / jari, cek kembali, data auto-save di browser jika terputus.

Simpan ke Database

Klik “Simpan ke Database” — sistem kirim ke Neon PostgreSQL dan beri ID. Toast konfirmasi muncul.

Admin Verifikasi

Admin login di /login → /admin → lihat detail, ubah status BARU→DIPROSES→SELESAI, export CSV.

Siap mengisi sekarang?

Butuh waktu ±5–7 menit. Pastikan Nama dan NIP terisi, lalu simpan. Admin akan menindaklanjuti status laporan Anda.
